# Contributing

Thank you for helping improve Native Calendar Todo.

1. Start from the `main` branch and create a small, focused branch for your change.
2. Keep existing Windhawk settings keys, mod ID (`win11-native-todo-calendar`), and task persistence compatible unless explicitly documenting a migration.
3. Test compilation in Windhawk; check task creation/editing/deletion, calendar date selection, holiday/workday colors, dark/light themes, and Shell restart behavior.
4. Include Windows build, Windhawk version, and test results with your pull request.
5. Respect upstream GPL v3 licensing and copyright/attribution comments.

Do not include private tasks, credentials, local user paths, or personal `.ics` files in issues or commits.
